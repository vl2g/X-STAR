# Licensing and attribution

The [MIT license](../LICENSE) covers this project's own code, configuration and software documentation. It does not license source photographs, dataset annotations, query translations, feature caches, model weights or paper figures. The SVG header uses outlined Liberation lettering; its [font notice](assets/brand/liberation-font-license.txt) is retained.

## Source datasets

- **Bharat Scene Text Dataset:** source photographs retain mixed, per-image licenses. Follow the [official dataset card](https://huggingface.co/datasets/Bhashini-IITJ/Bharat-Scene-Text-Dataset) and original image source records. Do not infer photograph rights from a software repository license.
- **RCTW-17:** the [official dataset page](https://rctw.vlrlab.net/dataset) provides downloads without an explicit named license. The [STR-Fewer-Labels licensing table](https://github.com/ku21fan/STR-Fewer-Labels/blob/main/data.md#license-of-datasets) reports original-author email permission for commercial and non-commercial use. This is reported correspondence, not an MIT or Creative Commons license.
- **TextCaps:** obtain data under its [upstream terms](https://textvqa.org/textcaps/dataset/) and preserve the terms of its source photographs. Raw TextCaps preparation is not implemented here.

Public release terms for X-STAR annotations, feature caches and weights are pending. No corresponding download or redistribution permission is granted by this software license. The included Chinese-source mapping records filenames and verification hashes, not source photographs or OCR transcripts.
