# Project website

This folder contains the project page, credited image assets and research documentation. The single dataset example and five retrieval rows are retained.

Publish with GitHub Pages: **Settings → Pages → Deploy from a branch → main → /docs → Save**. The repository owner, a maintainer or a role allowed to manage Pages settings must enable this once. The website address is https://vl2g.github.io/X-STAR/.

Updates to this folder deploy from the same repository after Pages is enabled. Use `python tools/check_project_page.py` for local-link, image and path checks. Photographs retain the source terms listed in `image-credits.html` and `content/image-credits.json`; MIT does not relicense them.
