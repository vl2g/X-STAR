# README header

`xstar-header.svg` is an original, text-only X-STAR wordmark on GitHub's dark background colour (#0d1117). Amber X and blue STAR, using outlined Liberation Serif Bold Italic lettering. It contains no external font dependencies, third-party logos or dataset photographs. Retain the [Liberation font notice](liberation-font-license.txt) with the outlined lettering.

The README resource badges use Shields.io's flat-square style, following the visual arrangement of IndicPhotoOCR without copying its logo. They link to real repository documentation; missing releases explicitly say "Pending". GitHub controls the surrounding README theme; the header graphic itself stays dark.
